== 커뮤니티 게시글

이 문서는 실제 보안 설정을 적용한 커뮤니티 컨트롤러의 `@WebMvcTest` 계약 테스트에서 생성한 예시를 안내합니다.
모든 요청에는 JWT 인증이 필요합니다. 활성 상태인 기수 소속 여부와 게시글별 관리 권한은 서비스 계층에서 확인합니다.
이 문서의 테스트는 실제 `SecurityConfig`의 인증·인가 진입점과 컨트롤러 위임을 확인하지만,
서비스 계층의 소속 및 권한 판정 자체는 검증하지 않습니다.

=== 대표 오류
필수 항목인 제목, 내용, 유형, 고정 여부가 없거나 길이 제한을 넘으면 `400 Bad Request`와 `COMMON_INVALID_REQUEST`를 반환합니다.
인증이 없으면 `401`, 인증은 되었지만 해당 기수 소속 또는 관리 권한이 없으면
서비스 정책에 따라 `404 Not Found` 또는 `403 Forbidden`으로 변환합니다.
