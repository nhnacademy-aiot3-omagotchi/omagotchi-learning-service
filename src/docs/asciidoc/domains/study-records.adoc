== 학습 기록

=== 공통 계약

* 모든 경로는 `/api/v1` 접두사를 사용합니다.
* `cohort-id`는 기수 식별자이고, `study-record-id`는 학습 기록 식별자입니다.
* 요청의 `startDateTime`·`endDateTime`은 KST 기준 `yyyy-MM-dd'T'HH:mm` 형식입니다. 초와 소수 초는 허용하지 않습니다.
* 서버는 입력한 KST 시각을 UTC `Instant`로 변환해 저장하고, 응답의 `startTime`·`endTime`·`createdAt`·`updatedAt`은 UTC ISO-8601로 반환합니다.
* `aggregationDate`는 KST 기준 날짜이며 `aggregationMonth`는 `yyyy-MM` 형식입니다.
* 수정은 본문의 `expectedVersion`, 삭제는 `X-RESOURCE-VERSION` 헤더로 낙관적 동시성 제어를 수행합니다. 최신 버전과 다르면 `409 Conflict`와 `STUDY_RECORD_VERSION_CONFLICT`를 반환합니다.
