== REST 외 통신 경계

=== WebSocket

재실 상태의 실시간 전송은 `/ws/**` 핸드셰이크와 STOMP 구독으로 동작하며 REST API 문서에는 포함하지 않습니다.

=== AMQP

RabbitMQ를 통해 Rule 품질 데이터를 소비하고 복구 큐를 처리하는 방식은 HTTP 엔드포인트와 구분되는 메시지 계약입니다.

=== Actuator

운영 관측 엔드포인트는 REST 업무 API와 구분합니다. `/actuator/health`와 `/actuator/prometheus`의 접근 범위는 운영 설정을 따릅니다.
