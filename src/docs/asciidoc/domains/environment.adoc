=== IoT 시뮬레이터 명령 실행

`environment.iot.simulator.enabled=true`일 때만 컨트롤러가 등록됩니다.
요청에는 `X-iot-TOKEN` 공유 토큰과 명령 본문을 사용하며, `success` 쿼리 파라미터의 기본값은 `true`입니다.
