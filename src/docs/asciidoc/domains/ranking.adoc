== 학습 랭킹

랭킹 API는 단독으로 구성한 MockMvc 계약 테스트에서 생성한 요청과 응답 예시를 제공합니다.
인증 토큰은 테스트 인증 주체로 직접 주입했으며, JWT 필터의 인증·인가 흐름은 이 문서의 범위에 포함하지 않습니다.
`maxRank`를 생략하면 전체 순위를 반환하고, 지정하면 해당 순위까지 반환합니다.
오늘 응답은 진행 중 타이머를 포함한 현재 집계일 기준이며 `calculatedAt`을 제공합니다.
과거 응답은 확정 기록만 포함하고 `startDate`와 실제 반영 마지막 날인 `includedThroughDate`를 제공합니다.
따라서 아직 확정된 날짜가 없으면 `includedThroughDate`는 `null`입니다.
