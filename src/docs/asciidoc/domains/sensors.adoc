== 센서

센서 API를 단독으로 구성한 MockMvc 계약 문서입니다. 테스트에서는 인증 주체를 직접 주입하므로
JWT 필터 자체의 인증·인가 동작은 검증하지 않습니다.

이 단독 구성 테스트에서는 컨트롤러의 요청·응답 본문만 확인합니다.
