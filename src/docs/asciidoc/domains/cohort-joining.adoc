=== 핵심 오류

빈 `expiresAt`, 빈 거절 사유 등 검증 실패는 `400 Bad Request`와 `COMMON_INVALID_REQUEST`를 반환합니다.
존재하지 않는 가입 코드·소속은 `404`, 중복 가입 신청은 `409`를 반환합니다. 이미 처리된 신청을 다시 처리하면 `400`과 `MEMBERSHIP_INVALID_STATUS_TRANSITION`을 반환합니다.

가입 코드가 존재하지 않으면 `JOIN_CODE_NOT_FOUND`를 반환합니다.
