== Telegram

Telegram 사용자 연동 API에는 Access JWT 인증이 필요합니다. 웹훅은 JWT 대신
`X-Telegram-Bot-Api-Secret-Token`을 검증하며, 문서 예시는 비밀값 자리표시자만 사용합니다.

=== 대표 오류
연동 토큰이 만료되었거나 이미 사용되었거나 연동 대상이 없으면 Telegram 도메인 오류가 `GlobalExceptionHandler`를 통해 `400 Bad Request` 또는 `404 Not Found`로 변환됩니다.
