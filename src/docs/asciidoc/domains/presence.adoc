== 재실 상태 API

재실 상태 API는 Access JWT의 `sub`에서 사용자 식별자를 읽습니다. 아래 세 API는 REST 하트비트와
Redis TTL을 이용해 재실 상태를 유지합니다.

=== 내 기수 재실 상태 조회

`GET /api/v1/cohorts/me/presence`

현재 로그인한 사용자가 접근할 수 있는 기수의 재실 상태 스냅샷을 반환합니다.
각 사용자의 닉네임, 대표 캐릭터, 상태와 스냅샷 생성 시각을 포함합니다.

=== 재실 상태 하트비트

`POST /api/v1/cohorts/me/presence/heartbeat`

`X-Presence-Session`은 Frontend BFF에서 생성해 전달하는 재실 세션 식별자입니다. 최초 호출은 세션을
등록하고 이후 호출은 TTL을 연장하며, 응답에 최신 스냅샷을 함께 반환합니다.

=== 재실 상태 이탈 알림

`DELETE /api/v1/cohorts/me/presence`

동일한 `X-Presence-Session` 값으로 식별한 재실 세션을 즉시 종료하며, 성공하면 `204 No Content`를 반환합니다.
호출이 실패하더라도 하트비트가 중단되면 Redis TTL에 따라 정리됩니다.

=== 실시간 전송 경계

위 REST API는 재실 상태를 등록·갱신·조회합니다. 실시간 변경 알림은 별도의 WebSocket 연결인
`/ws/**`와 STOMP 대상 경로 `/app/presence/heartbeat`, `/topic/cohorts/{cohort-id}/presence`
를 사용하며 이 문서의 HTTP 문서 조각에는 포함하지 않습니다. 재실 상태 REST API에는 SSE 엔드포인트가
없으므로 SSE 연결 방식으로 해석해서는 안 됩니다.
