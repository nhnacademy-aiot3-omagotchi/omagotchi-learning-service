== 팀

이 문서는 MockMvc를 단독으로 구성한 팀 컨트롤러 계약 테스트에서 생성한 실제 요청과 응답 예시를 안내합니다.
테스트는 `@AuthenticationPrincipal` 해석기를 등록하고 JWT의 `sub`를 요청자로 사용합니다.
단독 구성 테스트이므로 Spring Security 필터 체인의 인증·인가 흐름은 검증 범위에 포함하지 않습니다.

=== 대표 오류

필수 `targetUserId`가 없거나 팀 이름이 잘못되면 `400 Bad Request`를 반환합니다. 팀 소속이 없으면 상세 조회는 `404 Not Found`,
`MASTER`가 아닌 사용자가 팀원 변경·위임·해체를 요청하면 서비스 계층의 오류가 `403 Forbidden`으로 변환됩니다.
